# Feature: Setup

## Objetivo

Crear el entrypoint del bot y verificar que pueda conectarse a un chat

## Alcance

### Incluye

- Bot corriendo con mensaje exitoso
- Conexión exitosa a un sistema de persistencia
- Autorización de uso como bot
- Autorización de conexión a un chat 

### No incluye

- Comandos

## Comportamiento

- El bot se conecta a Twitch usando las credencias configuradas
- Verifica que tiene permisos en el canal target
- Registar error si no puede conectarse
- Cuando el bot tenga permisos en un canal muestra mensaje de conexión exitosa

## Casos borde

- Usuario da permisos mas de una vez
- Fallo al conectar a db 
- Credenciales invalidas
- Bot ya conectado

## Criterios de Aceptación

- Log de conexión exitosa a un canal
- Mensaje visible en el chat
- Conexión exitos a db
