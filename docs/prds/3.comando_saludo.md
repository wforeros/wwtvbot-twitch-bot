
# Feature: Comando para Saludar

## Objetivo

El bot debe responder "hola {usuario}" cuando se escriba `!hi`

## Alcance

### Incluye

- Comando `!hi` que puede ser usado por cualquier usuario
- Mensaje de saludo con el nick del usuario
- Delay para evitar spam del comando

### No incluye

- Permisos especificos de usuario
- Recepción de argumentos
- Aliases

## Comportamiento

- Usuario escribe `!hi`
- Bot cita y responde el mensaje con `Hola {usuario}!`
- Se muestra log con el mismo mensaje y quien invocó el mensaje (el log ya debería tener hora del mensaje)

## Casos borde

- El usuario envia un mensaje con "hi" al inicio pero con mas texto => Se ejecuta igual 
- El usuario envía el !hi sin que esté al inico => No se ejecuta
- Usuario usa el mensaje mientras tiene delay => Se ignora en el chat pero se muestra log
- Usuario escribe con mayusculas y minusculas "!hI" "!HI"... => Funciona igual

## Criterios de Aceptación

- Mostrar log cuando se ejecute el comando: "El comando !hi ha sido ejecutado por el usuario {user} en el canal {broadcaster}
- log cuando el usuario use el comando estando en delay: "Se escribe un log de forma silencionsa"
- Mensaje en el chat respondiendo el comando, con el formato: `Hola {usuario}!`
- El delay debe ser de 10s global
