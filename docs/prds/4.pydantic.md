# Feature: Implementar Pydantic

## Objetivo

Implementar Pydantic para facilitar el mapeo entre objetos de librerías como twitchio y el core del bot

## Alcance

### Incluye

Configuración de pydantic básica para ser usada en cualquier schema
Schema de ejemplo con Game para que pueda pasar del Game de twitchio al de Core
Creación del schema Game en core
Definición del mapeo entre ambas clases
Se usa Pydantic v2

### No incluye

Más clases, solo Game
Mapeo de funciones de twitchio Game

## Comportamiento

- Hago consulta a Games con twitchio
- Mapeo de Game twitchio a Game core
- Game core debe cumplir con la estructura completa 
- Mapeo solo de twitchio a core

## Casos borde

- Propiedades no usadas por el bot no deben ser mapeadas
- Funciones de Game no deben ser mapeadas

## Criterios de Aceptación

- Una instancia de Game twitchio debe ser convertible a core Game
- Debe existir al menos una prueba unitaria que valide el mapeo
- Pyright no debe reportar errores
- El mapeo debe fallar de forma controlada, si falta algún campo obligatorio
